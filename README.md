# Dhaval Chauhan — Portfolio

Personal portfolio of Dhaval Chauhan, full stack & AI automation engineer.

An interactive, single-page site built with React, Three.js and Motion:

- A particle hero that spells the name and reacts to the cursor
- A 3D galaxy of the 44 agents in agent.accountant, grouped into five suites
- Project case studies with overview, features, security and tech stack tabs
- Skills and certificates with real brand marks, each certificate linking to the original

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build   # outputs to dist/
```
